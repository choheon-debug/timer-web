# 타이머 (웹앱)

붉은 부채꼴 다이얼로 남은 시간을 보여 주는 타이머입니다. 아이폰·안드로이드 모두 인터넷 주소로 열고, 홈 화면에 추가해 앱처럼 씁니다.

- 위: 지금 시각, 가운데: 남은 시간만큼 붉은 다이얼(최대 60분 표시, 끌어서 설정), 아래: 남은 시간 디지털 시계
- 설정: 1분씩 ＋/−, 시간·분 직접 입력, 끝나는 시각으로 맞추기(최대 12시간), 끝날 때 읽어 줄 말(음성), 알림, 화면 켜짐 유지
- 끝나면 알람 소리·진동·음성, 알림을 켜 두었으면 알림도 보냄
- 앱을 껐다 켜도 진행 중이던 타이머를 이어서 보여 줌

화면이 꺼지거나 잠기면 휴대폰이 웹앱을 멈출 수 있어 알람이 늦거나 안 울릴 수 있습니다. 그래서 "화면 켜짐 유지"를 기본으로 켜 둡니다.

## 파일
- `index.html`: 앱 전체
- `sw.js`: 오프라인용 서비스 워커. 앱을 고치면 `VERSION`을 올려야 휴대폰에 새 버전이 퍼짐
- `manifest.webmanifest`, `icons/`: 홈 화면 아이콘
- `orbitron.woff2`: 디지털 시계 글꼴 Orbitron (SIL Open Font License), 숫자와 콜론만 담은 서브셋
